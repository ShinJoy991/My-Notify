# My-Notify

This project is made for my own to remind me about studying English when using computer. Best for studying, meeting, events time.

## Features:
- set a notify message, when time come it will popup remind in bottom right of the screen. It won't disrupt our window.
- Customize background of message for better visualize.
- Remind modes: repeat, one time, fixed time, warn x time before (for meeting), only between, only date.
- Remind notes mode: Add notes to different folders, pick folder to remind, or random all notes, or only a note.
- Can have sound notice.
